## 总入口
读取末尾“资产”JSON对象的 type，只执行一个对应分支：type 为 character 时只执行人物分支，type 为 scene 时只执行场景分支。资产 type、画幅、分支构图和 JSON 输出是硬约束，用户补充只能补充视觉细节，不得改变这些硬约束。输出必须是唯一合法 JSON object，且只含一个 prompt 字段。

## 人物填写规则
1. 优先使用人物描述中明确写到的信息。把口语化、分散或带情绪的描述改写成客观、具体、可直接画出的视觉特征；不用比喻，不用情绪化修辞，不加"8K""高清""杰作"等质量词。
2. 描述未覆盖但设定图必须有的槽位（内搭、下装、鞋、体型、脸型、妆容等），补一个与角色气质一致的中性默认值：最普通的款式和颜色，素颜。绝不添加新的辨识性特征，如疤痕、饰品、图案、异色、纹身。
3. 描述中的环境和场景动作（坐在地上、蜷缩在角落、靠墙、奔跑等）一律不进入提示词。把其中的情绪和姿态转成站姿下可表现的身体语言，只写在肩膀、背部、头部、视线、双臂和身体语言槽位里。
4. 所有槽位只用正向描述：写"有什么、是什么状态"，不写"没有什么"。
5. 一个特征只写一次，放在最合适的槽位，不在多个槽位重复。
6. 每个槽位用短语或短句，全文控制在 650 个汉字以内。
7. 材质列表只列出角色身上实际存在的材质，如皮肤、头发、棉布、皮革、金属。

## 人物参数默认值
用户未指定时：风格=写实真人；背景色=浅灰色；侧面方向=左侧面；光照=柔和均匀影棚光；整体基调=低对比度、中性色彩、自然写实。

## 场景分支
当资产 type 为 scene 时，忽略人物分支的四视图、人物槽位、人物填写规则和林晚示例，只输出一张1344×1024像素的「风格」单幅连续场景环境图提示词。场景提示词依次覆盖以下四段：
1. 单一连续空间或连续地貌的总体构图与唯一画面，不使用多格、四视图、分镜或平面图。
2. 观察位置、观察方向，以及前景、中景、背景的空间层次和主要视觉焦点。
3. 建筑或地貌、陈设或环境元素、时间、天气、光照、真实材质和项目风格。
4. 画面中不出现可辨识人物、文字、标志或水印，保持单幅连续环境的构图。
场景分支只把资产描述和风格改写为客观可绘制的环境特征；用户补充只能补充环境细节，不能加入人物、四视图、多格、分镜、平面图或文字标志。

## 输出格式
只输出唯一合法 JSON object，格式为 {"prompt":"填好的提示词正文"}，不得输出 Markdown、代码围栏、解释或其他字段。prompt 字段值是填好的分支提示词正文；人物分支保持模板的七个段落并去掉所有「」符号，场景分支保持上述四段并去掉说明性标题。JSON 必须可被直接解析，prompt 字段必须为非空字符串。
